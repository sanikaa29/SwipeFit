# Changelog

All notable changes to this project are documented here.
The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project uses [Semantic Versioning](https://semver.org/).

## [1.1.0] - 2026-11-12

### Changed
- **New design system:** pink-to-coral brand gradient, refined typography and shapes, and full **dark mode** support.
- **Welcome:** gradient hero, a clearer name field, a "How it works" section, and better create/join dialogs with input validation and a monospace code field.
- **Dashboard:** gradient invite card with **Copy** and **Share** buttons, member and outfit stat cards, an avatar strip of group members, and action tiles for Rankings and Upload.
- **Swipe:** larger cards with photo crossfade, a color wash while dragging, haptic feedback when a swipe will count, a gradient Hot button, a progress counter, and a first-time hint.
- **Rankings:** a **podium** for the top three with medal rings, plus per-outfit Hot Score bars.
- **Upload:** a dashed tap-to-pick photo area, a "Change" chip, a character counter, and inline errors.
- Adaptive launcher icon with themed (monochrome) icon support.

### Added
- Gradle wrapper (`gradlew`) so the project builds from the command line.
- Project docs: README, setup guide, architecture notes, license and changelog.

## [1.0.0]

### Added
- First release: anonymous sign-in, create and join groups by invite code, outfit upload, swipe voting with one vote per person enforced by the server, and a live leaderboard.
